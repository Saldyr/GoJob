# GoJob — contexte projet (pour Hermes)

App **Electron + React + TypeScript + Tailwind v4** : agrégateur d'offres d'emploi. Le process Electron (`electron/main.cjs`) fait tous les appels aux API d'emploi ; le rendu React (`src/`) affiche et filtre. Communication via `electron/preload.cjs` (IPC).

## Design system (réutiliser, ne pas réinventer)
- **Tokens** dans `src/index.css` (bloc `@theme`) : `--color-action:#9b35ff` (violet), `--color-electric:#00d9ff` (cyan), `--color-abyss:#080914`, ombres `--shadow-glass`/`--shadow-glow-*`, typo h1/h2/h3.
- **Composants UI** dans `src/components/ui/` : `Carte`, `Bouton`, `Champ`, `Interrupteur`, `PageHeader`, `DonutPlateformes`, `CarteOffre`, `LogoMark`. Assembler ceux-là plutôt que créer du neuf.
- Pièges connus : trap des cascade layers Tailwind v4 ; banding du `backdrop-filter` ; **chemins relatifs `./`** obligatoires pour `file://` (ex. `LogoMark` = `./logo-mark.png`, favicon = `./favicon.png`).

## Recette : ajouter une source d'offres
Toucher ces fichiers **dans cet ordre** :
1. `electron/main.cjs` — écrire `fetchXxx(...)` (normaliser via `offreEnLigne({...})`, utiliser `fetchTimeout` pour le délai 8 s), puis câbler dans le handler `chercher-en-ligne` : `if (xxx) taches.push(lancer('Xxx', () => fetchXxx(...)))`. Le handler parallélise (`Promise.all`) et **dédoublonne par URL**.
2. `src/electron-types.d.ts` — ajouter le param à `chercherEnLigne` (et à `testerCle` si clé).
3. `src/store/useStore.ts` — champ(s) settings (`xxxEnabled` + clé éventuelle) dans l'interface, `DEFAULT_SETTINGS`, `loadFromDisk`/`safeSettings`, et si secret l'exclure du `saveToDisk` (destructuration).
4. `src/utils/offres.ts` — ajouter à `PLATEFORMES`, `familleSource`, `ActivationPlateformes`, `canalActif`.
5. `src/components/OngletReglages.tsx` — carte (interrupteur + champ clé si besoin ; persister la clé dans la liste secrets de `set()` et la relire dans le `useEffect` `chargerSecrets`).
6. `src/components/OngletAccueil.tsx` — couleur dans `COULEURS_PLATEFORME`, union + cfg de `importerEnLigneCible`, bouton dans `IMPORTS`, et `onlineActif`/`cfg` de `toutRafraichir`.
7. `src/components/OngletOffres.tsx` — `cfg` de `lancerRecherche`.

## Pièges d'API (durement gagnés — non devinables)
- **Careerjet** (`https://search.api.careerjet.net/v4/query`) : clé en **HTTP Basic Auth** (clé = username, mdp vide) ; en-tête **`Referer` obligatoire** (sinon « Undeclared referrer ») ; **IP source à whitelister** dans le compte publisher → inadapté à une distribution large.
- **The Muse** : endpoint `https://www.themuse.com/api/public/jobs` (**sans `/v2/`**) ; clé optionnelle ; 20 offres/page → paginer.
- **RemoteOK** (`https://remoteok.com/api`) : **`User-Agent` obligatoire** ; 1er élément du tableau = métadonnées légales (filtrer sur présence de `position`).
- **Remotive** : flux gratuit plafonné à ~31 offres ; recherche serveur via `?search=`.
- **Arbeitnow** : sans clé, pas de recherche serveur → filtrer les mots-clés côté client.
- **France Travail** : OAuth `client_credentials`, scope `api_offresdemploiv2 o2dsoffre`, token sur `entreprise.francetravail.fr/.../access_token?realm=/partenaire`.
- **undici (fetch Node d'Electron main) envoie bien `Referer`** — ce n'est PAS strippé (vérifié).

## Sécurité des clés (règle absolue)
- Clés chiffrées via `safeStorage` → `gojob-secrets.enc` dans `app.getPath('userData')` (`%APPDATA%/gojob`).
- **Jamais** dans l'exe (le champ `build.files` = `dist/`+`electron/`+`package.json`) ni dans `localStorage` (les secrets sont retirés dans `saveToDisk`).
- Une install sur une autre machine démarre donc **sans aucune clé**. Ne jamais coder une clé en dur.

## Build & distribution
- `npm run electron:build` → `release/GoJob.exe` (portable) + `GoJob Setup x.y.z.exe` (installateur). `release/` est gitignoré.
- Distribution via **GitHub Release** (asset), pas de binaire commité.
- Garde anti-`ELECTRON_RUN_AS_NODE` en tête de `main.cjs` (l'env de VS Code/Hermes peut casser le lancement — ne pas la retirer).
